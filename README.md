# Codyssey Pre-course E1-2: 컴퓨터에게 명령 내리는 말(파이썬) 처음 배우기

## 프로젝트 개요

터미널에서 동작하는 콘솔 기반 퀴즈 게임. 코디세이 프리코스 미션 과제로, Python 기본 문법(변수/조건/반복/함수), 클래스와 객체(`Quiz`, `QuizGame`), 파일 입출력(JSON)을 활용한 데이터 영속성, Git을 이용한 버전 관리를 처음부터 끝까지 직접 구현하며 익히는 것을 목표로 한다.

메뉴에서 번호를 선택해 퀴즈를 풀고, 새 퀴즈를 추가하고, 등록된 퀴즈 목록과 최고 점수를 확인할 수 있다. 프로그램을 종료했다가 다시 실행해도 추가한 퀴즈와 최고 점수가 그대로 유지된다.

---

## 퀴즈 주제와 선정 이유

이 미션 자체의 학습 목표(Python 기초 / 클래스와 객체 / 파일 입출력 / Git 기초)를 퀴즈 소재로 삼았다. `bool`/`while`/`self`/`json` 같은 Python 기본 개념부터 `git clone`/`git merge` 같은 Git 명령어까지, 이 과제를 진행하며 실제로 배운 내용을 퀴즈로 다시 확인해보는 형태다. 미션을 완주하면 자연스럽게 퀴즈도 다 풀 수 있게 되는 구조를 의도했다.

## 기능 목록

| 메뉴 | 기능      | 설명                                                                                                                                                        |
| ---- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 퀴즈 풀기 | 등록된 퀴즈를 순서대로 출제, 정답 입력 시 정답/오답 표시, 전체 완료 후 결과(정답 수/점수)와 최고 점수 갱신 여부 표시. 등록된 퀴즈가 없으면 안내 메시지 출력 |
| 2    | 퀴즈 추가 | 문제/선택지 4개/정답 번호를 입력받아 새 퀴즈 등록                                                                                                           |
| 3    | 목록 보기 | 등록된 퀴즈 목록(문제 텍스트) 출력. 등록된 퀴즈가 없으면 안내 메시지 출력                                                                                   |
| 4    | 점수 확인 | 현재까지의 최고 점수 확인, 아직 풀지 않았으면 안내 메시지 출력                                                                                              |
| 5    | 종료      | 데이터 저장 후 안전하게 종료                                                                                                                                |

공통으로 숫자 입력이 필요한 곳(메뉴 선택, 정답 번호 등)은 빈 입력/숫자가 아닌 입력/범위 밖 입력을 모두 검증하고 재입력을 요청하며, 텍스트 입력이 필요한 곳(퀴즈 추가 시 문제/선택지)도 빈 입력을 검증하고 재입력을 요청한다. `Ctrl+C`, `Ctrl+D` 등으로 강제 종료를 시도해도 비정상 종료 없이 저장 후 안전하게 종료된다.

```
.
├── main.py         # 프로그램 진입점 (QuizGame 생성 및 실행)

├── state.json       # 퀴즈 목록 및 최고 점수 저장 파일 (실행 시 자동 생성, 저장소에는 미포함)

└── .gitignore
```

## 데이터 파일 설명(`state.json` 경로/역할/스키마)

- **경로**: 프로젝트 루트(`./state.json`), UTF-8 인코딩
- **역할**: 등록된 퀴즈 목록과 최고 점수를 저장해, 프로그램을 종료했다가 다시 실행해도 데이터가 유지되도록 함. 파일이 없으면(최초 실행) 기본 퀴즈 데이터로 시작하고, 파일이 손상되었거나 형식이 올바르지 않으면 안내 메시지를 출력한 뒤 기본 데이터로 초기화한다.
- **저장 시점**: 퀴즈 추가 후, 퀴즈를 푼 직후, 프로그램 종료(정상/강제 종료 모두) 시
- **스키마**:

  ```json
  {
    "quizzes": [
      {
        "question": "Python의 창시자는?",
        "choices": ["Guido", "Linus", "Bjarne", "James"],
        "answer": 1
      }
    ],
    "best_score": 3
  }
  ```

  - `quizzes`: 퀴즈 목록. 각 항목은 문제(`question`), 선택지 4개(`choices`), 정답 번호(`answer`, 1부터 시작)로 구성
  - `best_score`: 최고 점수(0~100점). 아직 한 번도 퀴즈를 풀지 않았다면 `null`
